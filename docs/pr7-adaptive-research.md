# PR7 自适应停止与配对评测

## 目标

PR6 跑通了零改写基线与有界补检 Agent 的对照，但也暴露了三个会污染结论的问题：两组独立调用模型会引入采样噪声；QASPER 的论文级问题曾在整个 Collection 中检索；证据没有新增时，图仍可能继续判断和改写。PR7 修正评测协议并给无效补检设置止损条件，不预设多轮一定优于单轮。

## 运行时约束

### 无新增证据时停止

每轮检索先按文档 ID 与 Chunk ID 去重，并记录 `new_evidence_count`。一次改写后的检索若没有带来新证据，且 `PAPEROPS_RESEARCH_STOP_ON_STAGNANT_RETRIEVAL=true`，图直接返回 `insufficient_evidence`，`stop_reason=stagnant_retrieval`，不再为相同证据支付充分度判断和下一轮改写调用。

图还区分以下停止原因：

- `duplicate_query`：模型生成了已经尝试过的查询；
- `stagnant_retrieval`：改写后没有新增去重证据；
- `budget_exhausted`：用完配置的改写预算。

这些状态会通过查询 API 和评测报告暴露，方便区分“主动止损”与“服务失败”。

### 最小相关证据集

充分度判断必须同时输出 `relevant_citation_ids`。普通代码验证 ID 是否属于已检索证据、是否去重，并限制最多选择 `PAPEROPS_RESEARCH_MAX_SELECTED_EVIDENCE` 条；回答模型只接收这组证据，而不是整个累计候选集合。该约束不增加模型调用，用来减少无关上下文和引用扩散。

回答仍对未知、重复或缺失引用失败关闭。唯一的窄修复是：若模型只声明了一个有效引用，且正文仅漏写同一个内联标记，系统确定性地把标记补到句末。多个引用的位置不明确时不会猜测。

## 配对消融协议

`evaluate-agent` 使用 `shared_initial_retrieval_and_assessment_v1`：

1. 每个问题只执行一次初始检索与充分度判断，并在判断节点后保存 checkpoint；
2. 初始证据充分时，基线和 Agent 复用同一次回答生成；
3. 初始证据不足时，零改写基线按反事实路径立即拒答，Agent 从相同 checkpoint 恢复并执行有界改写；
4. 报告额外给出基线漏答数、Agent 恢复数、恢复率、每次恢复的增量 token 和停滞停止率。

这个协议隔离了“是否继续补检”这一控制变量，也避免把两次独立模型采样的差异误认为 Agent 收益。代价是基线延迟属于配对实验中的共享前缀成本，不等同于两个生产请求独立运行时的墙钟时间。

可使用可重复的 `--query-id` 只复跑指定问题，定位结构化失败而不必重复消费整个数据集。

## QASPER 论文作用域

QASPER 的问题针对一篇指定论文。PR7 生成 `0.3-paperops-v3-document-scoped` 数据时，为每个查询保存 `document_id`；评测索引建立逻辑文档 ID 与后端文档 ID 的双向映射，并把 `expected_document_id` 传给检索后端。转换器与数据校验会拒绝未知文档作用域或落在其他论文中的标注证据。

PR6 的早期真实诊断使用 Collection 级检索，曾使代词问题从其他论文召回看似相关的段落。该报告只保留为历史故障证据，不能继续用于判断改写效果。

## 真实模型小样本诊断

2026-08-08 使用 `deepseek-v4-flash`、原生 FTS5/BM25、Top K 10、最多两次改写，在带论文作用域的 QASPER dev 顺序子集上运行 3 个可回答与 3 个一致不可回答问题。数据集 SHA256 为 `577036fd1850b3da86fd35dd82c433e35e001d398a72ffec483dc11164019ba2`。

基线漏掉 1 个可回答问题，Agent 恢复 0 个，因此当前小样本的 `answerable_recovery_rate=0`，不能声称改写带来了质量收益。两个不可回答问题在改写后没有新增证据并触发停滞停止，证明止损路径有效，但没有改善任务结果。

这次运行还暴露了两类失败：一个回答声明了正确的单引用，却漏写正文标记；另一个标注为不可回答的“evaluation methods”问题被模型解释为同论文中的“analysis methods”。前者已通过窄归一化和单元测试修复，定向真实复跑完成；后者是语义边界错误，保留为负结果，后续应通过更大样本评测判断是否需要专门的蕴含校验，不能靠关键词规则掩盖。

## 结论边界

PR7 支持以下结论：配对协议能够降低独立采样噪声；论文级作用域消除了跨论文召回污染；停滞停止与证据筛选能够限制无效调用。在当前 3+3 诊断集上，有界改写没有超过零改写基线，额外消耗 5,241 tokens。

它不支持“Agent 已优于单轮 RAG”“6 个问题具有统计显著性”或“QASPER 结果可直接代表中文无人机语料”。下一阶段若继续优化，应先扩大固定、论文级评测集，再决定改写是否默认启用。
